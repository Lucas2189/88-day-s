# Templates

| Fichier | Usage |
|---|---|
| `content-brief.md` | Brief d'un contenu (objectif, recherche, hooks). Copier dans `briefs/`. |
| `claims-table.md` | Tableau des affirmations et sources officielles. |
| `storyboard.md` | Storyboard minuté, versions A et B. |
| `pre-posting-checklist.md` | Contrôle final avant que Lucas publie. |
| `tools/make_voiceover.py` | Voix off IA gratuite et locale (Kokoro-82M). |
| `tools/render_reel.py` | Rendu vidéo 9:16 à l'identité officielle (Pillow + ffmpeg), musique originale générée en code, loudness −16 LUFS, SRT et cover. Exemples de `spec.json` dans `drafts/2026-11-07_*/`. |

Ne pas remplir les modèles sur place : les copier.
