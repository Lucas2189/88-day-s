# Checklist avant publication

## Contenu
- [ ] Le problème ou le bénéfice est clair dès la 1re frame, sans le son.
- [ ] Une seule idée principale, un seul CTA.
- [ ] Chaque affirmation est dans le tableau des affirmations, avec une source officielle.
- [ ] Aucune affirmation d'éligibilité au visa ; rien ne laisse entendre qu'Eazy88 valide un travail ou garantit un visa, un emploi ou un logement.
- [ ] Aucune statistique, témoignage, commentaire ou écran inventé.
- [ ] Écrans de l'app réels, données de démo, label « Real app screens · demo data ».
- [ ] Fonctionnalités montrées présentes dans la section 1 de `product/product-facts.md` et contenu actif confirmé.
- [ ] App Store uniquement (pas de Google Play tant qu'une fiche n'est pas confirmée).
- [ ] Musique originale ou licenciée pour cet usage.
- [ ] Identité de marque conforme à `brand/brand-identity.md`.

## Technique
- [ ] ffprobe : h264 + aac, 1080×1920, 30 fps, 30–40 s.
- [ ] Planche de frames du MP4 final vérifiée (hook, scènes, fin) : rien de coupé, rien hors zone sûre.
- [ ] Sous-titres = voix mot pour mot ; SRT cohérent.
- [ ] Loudness ≈ −16 LUFS, TP ≤ −1,5.
- [ ] Fichiers nommés selon `exports/README.md`.

## Publication (Lucas uniquement)
- [ ] Label TikTok « AI-generated content » activé.
- [ ] Légende en anglais relue ; 3–5 hashtags.
- [ ] Publication, programmation et toute dépense validées par Lucas.
