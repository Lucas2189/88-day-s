# Exports

Livrables **finaux** uniquement, après contrôle qualité.

## Convention de nommage
Un dossier par contenu : `AAAA-MM-JJ_<Topic>/`

| Fichier | Nom |
|---|---|
| Vidéo, version A (organique) | `Eazy88_TikTok_<Topic>_A.mp4` |
| Vidéo, ouverture B (test payant éventuel) | `Eazy88_TikTok_<Topic>_B.mp4` |
| Sous-titres | `Eazy88_TikTok_<Topic>.srt` |
| Voix seule | `Eazy88_TikTok_<Topic>_Voiceover.wav` |
| Cover 1080×1920 | `Eazy88_TikTok_<Topic>_Cover.png` |
| Légende + hashtags (anglais) | `Eazy88_TikTok_<Topic>_Caption.txt` |
| Paquet complet | `Eazy88_TikTok_<Topic>.zip` |

`<Topic>` en PascalCase court, sans espaces (ex. `HarvestChecklist`).
Un export n'est jamais publié sans l'accord de Lucas.
