## Pourquoi vous devez publier vous-même dans les groupes
Meta a supprimé la possibilité, pour toute application, de publier dans des groupes (« Groups API » et permission `publish_to_groups` dépréciées en v19.0, retrait prévu le 22 avril 2024). Aucun outil, moi compris, ne peut poster dans un groupe à votre place. Source : [Graph API v19.0 changelog](https://developers.facebook.com/docs/graph-api/changelog/version19.0).

Ce qui reste possible : publier et programmer sur une **Page** Facebook (pas un profil, pas un groupe) via le connecteur Windsor.ai « facebook_organic » : textes, photos, vidéos, Reels, Stories. Toujours avec votre accord explicite pour chaque publication (règle n° 10 du projet).

## Comment publier sans se faire bannir
- **Lire le règlement** de chaque groupe. Beaucoup interdisent toute promotion.
- **Un post par groupe et par semaine maximum.** Alternez les versions A et B : coller le même texte dans plusieurs groupes peut être pris pour du spam.
- **Espacer** les publications (pas 10 groupes en 10 minutes).
- **Répondre aux commentaires** dans l'heure qui suit, sans renvoyer vers l'app sauf si on vous le demande.
- **Ne pas envoyer de messages privés** à des inconnus.
- **Post 6 (présentation) :** demander d'abord à l'admin. **Mon conseil : attendre que la fiche App Store soit corrigée** (note de 2,0/5 aujourd'hui, avis sur le décompte des jours), sinon les gens qui cliquent voient d'abord 2 étoiles.
- Si un post est supprimé : ne pas le republier, demander à l'admin ce qui est permis.
